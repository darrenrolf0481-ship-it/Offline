## 2025-05-18 - Workspace Explorer File Lookup & Shared Component Memoization
**Learning:** In single-file React architectures where top-level App state changes on every keystroke (e.g., input fields) or interval tick (5s diagnostic monitor), nested array filters like `files.filter(f => f.folderId === folder.id)` run $O(\text{Folders} \times \text{Files})$ on every render. Creating a Map lookup using `useMemo` reduces lookup to $O(1)$ ($O(\text{Files} + \text{Folders})$ overall). Additionally, memoizing pure functional UI components (`SidebarItem`, `StatCard`) with `React.memo` avoids redundant Virtual DOM re-renders on global state changes.
**Action:** Always prefer indexing nested relational arrays with `useMemo` Map lookups and memoizing layout components in state-heavy single-page React apps.
